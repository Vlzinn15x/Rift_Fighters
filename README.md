# Rift Fighters 🎮

Repositório do jogo HTML **Rift Fighters V33**, para PC e celular.

## Status
A publicação automática no **GitHub Pages** foi preparada, mas o pacote do jogo ainda **não foi enviado integralmente**. É necessário adicionar os arquivos de `public/` e os demais arquivos do projeto para jogar.

## Enviar o jogo
1. Extraia o pacote `Rift_Fighters_V33_PRONTO_GITHUB.zip` no computador.
2. Abra o repositório no **GitHub Desktop**.
3. Copie o conteúdo extraído (pastas `public/`, `.github/`, `worker/`, `migrations/` e arquivos como `package.json`) para a pasta local do repositório.
4. Faça **Commit to main** e **Push origin**.
5. Em **Settings → Pages**, selecione **GitHub Actions** em Source.

O GitHub Pages publica **modo solo e treino**. Para salas online entre jogadores, é necessário publicar o servidor do projeto com Cloudflare Workers e D1. Consulte o README completo incluído no ZIP.

**Importante:** não envie senhas nem tokens dentro do repositório.
